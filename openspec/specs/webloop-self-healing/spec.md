## Requirements
### Requirement: Lenient AST JSON auto-repair for Web tool calls
The tool execution engine SHALL automatically repair malformed JSON arguments (including unbalanced braces, trailing commas, unescaped quotes, unescaped raw newlines) generated by web chat sessions before returning validation errors to the client.

#### Scenario: Auto-repair unclosed JSON braces
- **WHEN** a web model generates `<tool_call>{"name":"Bash","arguments":{"command":"ls -la"` without closing braces
- **THEN** the self-healing parser automatically completes the JSON structure and emits a valid tool call

#### Scenario: Transparent retry on unrecoverable tool call failure
- **WHEN** a web session generates completely unparseable text instead of requested tool markup
- **THEN** the gateway initiates an immediate transparent retry or failovers to the next provider in pool within 1.5 seconds without dropping the SSE stream
